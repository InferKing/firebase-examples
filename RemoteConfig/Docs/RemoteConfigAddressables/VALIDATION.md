# Ревью и проверка упрощённого примера

Исправлено:
- Все приватные поля расположены перед методами и используют _camelCase; сериализованные ссылки сохранены.
- InstantiateAsync / ReleaseInstance управляют экземпляром и его ресурсами вместе.
- После ошибки инициализации Firebase можно повторить попытку той же кнопкой.
- Вместо конкурирующих обновлений кнопка заблокирована на время запроса.
- При ошибке адреса остаётся предыдущий облик; при закрытии сцены освобождается и поздно завершившаяся загрузка.

Убраны генератор сцены, диагностические кнопки, прогресс, счётчик запросов и дублирование параметров скорости/масштаба. Остались три компонента, один параметр и одна кнопка.

Проверено в Unity 6000.3.5f2: компиляция; HTTP-загрузка ice/lava после очистки их кэша; ошибочный адрес; возврат к default; повтор после ошибки; блокировка конкурирующей загрузки; уничтожение объекта при загрузке. Все проверки прошли. Тестовый HTTP-сервер остановлен.

Проверки выполнялись в отдельной временной копии с реальными bundles. Публикация параметров в Firebase и отдельная сборка приложения в этот проход не проверялись. Ошибка visuals/missing в тестовом журнале ожидаемая.
