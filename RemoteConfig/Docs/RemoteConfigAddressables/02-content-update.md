# Пример 2: новый prefab после выпуска

Следующий этап, пока не реализован. Скрипты будут в той же папке RemoteConfigAddressables, сцена — отдельная.

1. Сохранить исходный билд приложения и его addressables_content_state.bin.
2. Добавить третий prefab с новым адресом, использующий существующий код.
3. Собрать совместимое обновление Addressables и опубликовать bundles, каталог и hash.
4. Обновить каталог на клиенте перед загрузкой нового адреса.
5. Переключить cube_visual_key через Firebase.
6. Проверить новый облик на исходном приложении без его пересборки.
