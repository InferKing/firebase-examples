# Remote Config + Addressables

[Запуск первого примера](01-switching.md) · [Следующий пример](02-content-update.md)

Три скрипта в Assets/Scripts/RemoteConfigAddressables:
- RemoteConfigAppearance: получить и активировать параметр Firebase.
- AddressableCubeView: заменить prefab, освободить предыдущий.
- AppearanceDemoPanel: кнопка обновления и одна строка состояния.

Старый пример Remote Config находится отдельно и не изменён.
